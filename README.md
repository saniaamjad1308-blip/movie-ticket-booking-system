# Movie Ticket Booking System

## Project Overview
The Movie Ticket Booking System is a DBMS mini-project developed using Oracle SQL in Oracle APEX. It manages movies, customers, show schedules, and ticket bookings.

## Technologies Used
- Oracle Database
- Oracle APEX
- SQL
- GitHub

## Database Tables
1. Movies
2. Customers
3. Shows
4. Bookings

## Features
- Store movie and customer details
- Manage show schedules and ticket prices
- Record ticket bookings
- Calculate booking amounts and total revenue
- Generate reports using JOIN, COUNT(), SUM(), and GROUP BY
- Maintain data integrity using primary and foreign keys

## How to Run
1. Open Oracle APEX.
2. Navigate to SQL Workshop.
3. Create the four tables using the provided SQL script.
4. Insert the sample records.
5. Execute the queries to view booking details and reports.
